Как развернуть в IntelliJ IDEA
Установите PostgreSQL (если ещё нет) и запомните пароль пользователя postgres.
Создайте базу данных. Откройте pgAdmin или psql и выполните: CREATE DATABASE clubs_db;. Таблицы создадутся сами при первом запуске.
Распакуйте архив и откройте папку clubs-site в IntelliJ: File → Open, выберите файл pom.xml, затем Open as Project.
Подождите, пока Maven скачает зависимости (прогресс внизу окна).
Проверьте JDK. В File → Project Structure → Project должен стоять JDK 17 или новее. Если его нет, выберите Download JDK.
Настройте подключение. Откройте src/main/resources/application.properties:
spring.datasource.password — пароль вашего PostgreSQL;
app.admin.username и app.admin.password — логин и пароль для редактирования (смените их обязательно).
Запустите. Откройте ClubsApplication.java и нажмите зелёный треугольник рядом с main.
Откройте в браузере http://localhost:8080.

Что сделано на странице кружков

Список /clubs:

По 10 кружков на странице, внизу переход «← Назад», номера страниц, «Вперёд →». При 18 тестовых кружках получается 2 страницы.
В каждой строке серый скруглённый прямоугольник вместо изображения, название и описание, обрезанное до 300 символов (с многоточием, если длиннее).
Кружок открывается по клику на любое место строки.

Страница кружка /clubs/{id}:

Слева большой серый прямоугольник, название, описание, требования, расписание, организатор, место и контакты. Сверху ссылка «← К списку кружков», которая возвращает на ту страницу списка, где этот кружок находится.
Справа вертикальная панель: стрелка ▲, 6 серых скруглённых «изображений», стрелка ▼. Стрелки переключают на предыдущий и следующий кружок, клик по «изображению» открывает этот кружок. Текущий кружок обведён синей рамкой, на первом и последнем стрелка неактивна.
Когда появятся настоящие картинки, их достаточно подставить вместо серых блоков в clubs.html и club.html. Названия кружков сейчас видны во всплывающей подсказке над миниатюрой.
На узком экране (телефон) панель уходит под описание и становится горизонтальной.

Дата обновления

Под названием кружка и в списке стоит маленькая серая пометка «Обновлено: 08.11.2026». Дата ставится только при успешном сохранении формы, при ошибках валидации она не меняется.

Роли и вход

Студент регистрируется сам на /register: логин, пароль, ФИО, группа, курс (всё обязательно).

Видит списки кружков и мероприятий.
На странице кружка нажимает «Записаться на кружок». Повторно записаться нельзя.
Раздел «Уведомления»: «Заявка отправлена» и позже ответ организатора.

Организатор (аккаунты создаёт администратор): ФИО и контакты хранятся в профиле и показываются в карточке его кружков.

Создаёт и редактирует только свои кружки и мероприятия, чужие открыть нельзя (ошибка 403).
Страница «Заявки»: дата, кружок, ФИО, группа, курс студента. Можно написать свой ответ или нажать «Автоответ».
Автоответ задаётся в форме кружка. Если поставить галочку «Отправлять сразу при поступлении заявки», студент получит его мгновенно, без участия организатора.

Администратор видит список всех пользователей и создаёт новых (любой роли). Первый администратор берётся из application.properties (app.admin.username и app.admin.password).
